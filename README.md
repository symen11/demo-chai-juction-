# Chai Junction — Responsive VS Code Project

A responsive demo digital menu website built with HTML, CSS, and JavaScript.

## Run in VS Code
1. Extract this folder.
2. Open the `chai-junction-responsive` folder in VS Code.
3. Open `index.html` in your browser, or use Live Server.
4. Edit `css/style.css` for layout/design and `js/script.js` for interactions.

## Responsive changes
- Mobile navigation menu with an accessible toggle.
- Fluid typography and flexible hero artwork.
- Menu cards adapt from three columns to two and then a compact single-column layout.
- Offers, special section, visit cards, QR area, and footer stack on small screens.
- Touch-friendly buttons and visible keyboard focus.
- Reduced-motion preference support.

## Demo notes
- Menu names/prices and shop timings/location are samples/placeholders.
- WhatsApp ordering asks for a number because no shop number is configured.
- QR uses the current page URL. Deploy first for a public customer QR.
- Front-end demo only; no payment processing or backend order storage.
